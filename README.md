# Kamil Hankour academic website

A complete static website prepared for the GitHub account `kamilhankour`.

Intended GitHub Pages address: https://kamilhankour.github.io/

## Publish

1. Create a public repository named exactly `kamilhankour.github.io` in the `kamilhankour` account. If that repository already exists, review its contents before adding or replacing files.
2. Upload the contents of this folder to the repository's `main` branch. `index.html` must be at the repository root. Upload the extracted files and the `assets` folder, not the ZIP archive or an extra enclosing folder.
3. Open the repository's Settings, then Pages. Under Build and deployment, select Deploy from a branch. Select `main` and `/(root)`, then Save.
4. Wait for the Pages deployment to finish. GitHub displays the published address in the Pages settings.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Update the site

Edit the HTML pages to update content. `styles.css` controls the appearance and `site.js` controls the mobile menu. To update the CV download, replace `assets/Kamil_Hankour_CV.pdf`. Changes committed to the publishing branch will be republished by GitHub Pages.

This package contains the six completed pages and the CV provided on September 8, 2026. All page links and assets use relative paths. No build tools or ChatGPT account are required to serve the site.
